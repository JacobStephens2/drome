# Completing the goals
There should be a way to mark the 10 pages as read from the goal overview, without having to open that menu.

# Backfilling
The user should be able to go to history, click a prior day, and have a way to edit what was done or not done on that day. For example, if I'm on day 25, I should be able to go to history, click day 23, and have a way to edit it.

# Settings
The day cutoff time should be editable.

Account and Groups should be above Reading.

# Accounts
Users should be able to sign in with either Apple or email six digit one time passcodes.

# Groups
If the user is in a group, there should be a group icon in the main menu at the bottom of the app.
